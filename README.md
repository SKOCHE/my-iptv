# SKOCHE IPTV — автоматический сборщик

Проект собирает варианты потоков для 41 заданного канала и формирует:
- `favorites.m3u` — только URL, которые пользователь подтвердил воспроизведением в Televizo;
- `test_candidates.m3u` — найденные варианты для проверки на устройстве;
- `update_report.txt` — отчёт по источникам и результатам проверок.

## Файлы
- `channels.json` — список каналов, источники и вручную подтверждённые URL.
- `update_playlist.py` — полный сбор M3U, сопоставление названий, HTTP-проверка и FFmpeg-проба.
- `validate_config.py` — проверка конфигурации.
- `.github/workflows/auto_update.yml` — расписание и ручной запуск.

## Проверки и ограничения
- Полные M3U скачиваются в пределах `max_file_bytes`; больше нет обрезания на первых 4096 байтах.
- Добавлены прямые источники ngrch и dearbulut к имеющимся источникам.
- Wink/Zabava CDN исключается: пользователь получал территориальную заглушку.
- Проверки на GitHub runner не гарантируют воспроизведение через Ростелеком.
- `FFMPEG_OK` означает декодирование видео, но не подтверждает название канала.
- Автоматические кандидаты не публикуются в `favorites.m3u`.

## Запуск
GitHub → Actions → `IPTV Aggregator — collect, check and publish` → `Run workflow`.
