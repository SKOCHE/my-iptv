ЧТО ЗАГРУЗИТЬ В РЕПОЗИТОРИЙ SKOCHE/my-iptv

Заменить/добавить файлы:
  update_playlist.py
  .github/workflows/auto_update.yml
  channels.json

Оставить существующий favorites.m3u — он является исходной копией с адресами,
которые будут использоваться как резервные, если новый проверенный поток не найден.

После загрузки откройте GitHub -> Actions -> Auto Update IPTV Playlist -> Run workflow.
Скрипт всегда формирует все 41 названия. Новая ссылка подставляется только при точном
совпадении названия, успешном GET и отсутствии такого URL у другого канала.
Если замена не найдена, старый URL сохраняется; это явно отмечается в update_report.txt.

Важно: GET-проверка подтверждает доступность HLS-плейлиста, но не может гарантировать,
что внутри действительно транслируется именно заявленный телеканал. Для полной
идентификации содержимого нужен отдельный анализ видеопотока/EPG.
