IPTV v10 — исправление региональных потоков Барнаула (+4)

В архиве находится один файл:
update_playlist.py

Что исправлено:
- НТВ (+4) и Россия 1 HD (+4) обрабатываются ДО поиска channel_id в каталоге.
- Поэтому Россия 1 HD (+4) больше не пропускается только из-за отсутствующего channel_id.
- Для этих двух каналов используется только явно заданный региональный URL; автоматического отката на московский поток нет.
- МИР (+4) не подменяется обычным потоком без подтверждения региональной версии.
- Остальная логика генерации и workflow остаются без изменений.

Установка:
1. Распаковать архив.
2. Заменить в корне GitHub update_playlist.py.
3. Commit changes.
4. Запустить GitHub Actions один раз.
5. Скачать update_report.txt из Artifacts и проверить НТВ/Россия 1 в Televizo.

Важно:
Скрипт синтаксически проверен. Реальное воспроизведение региональных URL и соответствие эфира Барнаулу здесь не подтверждались. Успешный FFmpeg decode не доказывает, что это нужный телеканал или нужная региональная сетка.
