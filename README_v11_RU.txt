IPTV v11 — исправление количества каналов в Televizo

Причина, по которой в телевизоре было только 20 каналов:
предыдущий скрипт добавлял в favorites.m3u только те каналы, для которых
FFmpeg находил декодируемый поток. Остальные 21 канала полностью исключались
из M3U, поэтому Televizo показывал только 20 записей.

Что изменено в v11:
1. Скрипт формирует ровно 41 запись — по одной на каждый канал из channels.json.
2. Если проверенный поток не найден, канал всё равно отображается в Televizo
   с пометкой [НЕТ ПОТОКА] и группой «Нет потока».
3. Для таких записей используется зарезервированный домен example.invalid.
   Это намеренно нерабочий адрес: он не подменяет канал чужим видео.
4. Для МИР (+4) запрещена подстановка обычного потока МИР из Казахстана.
5. Региональные потоки НТВ (+4) и Россия 1 HD (+4) остаются кандидатами;
   успешное декодирование не подтверждает, что это именно Барнаул +4.
6. Публикация больше не отменяется только из-за малого количества потоков.

Важно:
- В Televizo будет видно 41 канал, но записи [НЕТ ПОТОКА] воспроизводиться не будут.
- Это исправляет отображение полного списка, но не создаёт отсутствующие трансляции.
- Не заменяйте channels.json и workflow. Для установки замените только
  update_playlist.py в корне репозитория GitHub.

Установка:
1. Распакуйте архив.
2. Замените update_playlist.py в корне репозитория.
3. Сделайте Commit changes.
4. Откройте Actions и запустите Build strict Android TV IPTV playlist вручную.
5. После успешного запуска обновите плейлист в Televizo.

Ожидаемый результат в update_report.txt:
SUMMARY: playable_candidates=X/41; placeholders=Y; total_playlist_entries=41/41
где X + Y = 41.
