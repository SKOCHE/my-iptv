IPTV v12 — расширенный поиск источников

Что изменено:
- Поиск больше не ограничен только каталогом iptv-org и точным channel_id.
- Добавлены дополнительные кандидаты из независимых публичных M3U-репозиториев.
- Дополнительные URL проходят ту же проверку FFmpeg, что и остальные потоки.
- Для каналов без однозначного ID теперь тоже проверяются дополнительные кандидаты.
- МИР (+4) получает отдельный кандидат Mir +4, а не обычную московскую версию.
- Россия 1 (+4) использует региональный endpoint Барнаула; это SD-поток, не HD.
- Известные ранее плохие домены остаются заблокированы.

Важно:
- Успешное декодирование означает только наличие видеопотока, а не подтверждение телеканала.
- Некоторые публичные URL могут быть временными, недоступными или требовать регионального доступа.
- Названия Viasat History/Nature могут соответствовать ребрендингу viju History/Nature — проверь картинку в Televizo.
- НТВ (+4) пока не получил подтверждённый отдельный барнаульский источник; московский НТВ не подставляется.
- После замены update_playlist.py запусти GitHub Actions и пришли новый update_report.txt.
